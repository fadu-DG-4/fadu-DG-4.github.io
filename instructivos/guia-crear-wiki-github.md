# ¿Cómo crear una Wiki en GitHub?

**GitHub Wiki** es probablemente la opción más simple para crear y publicar rápidamente páginas *Wiki*. Está disponible gratis para cualquier repositorio público y permite editar directamente desde GitHub o clonar la wiki como repositorio Markdown. También admite sidebar y footer personalizados.

## Antes de empezar
Vas a necesitar:

- Una cuenta creada en GitHub.
